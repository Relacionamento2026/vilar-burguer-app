# Vilar Burguer — Cardápio Digital

Protótipo navegável de cardápio e pedidos com carrinho, adicionais e finalização via WhatsApp.

## Hospedagem pública com nome da marca

[![Publicar na Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Relacionamento2026/vilar-burguer-app)

Este botão utiliza o arquivo `render.yaml` para publicar um site estático gratuito na Render, com um endereço `*.onrender.com`. A disponibilidade do nome depende da plataforma.

## Atenção antes de pedidos reais

Esta versão é demonstrativa. Confirme preços, telefone comercial, taxa e área de entrega, horários e formas de pagamento antes de enviar para clientes. A finalização abre uma mensagem no WhatsApp para confirmação manual pelo cliente.
